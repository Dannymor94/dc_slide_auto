# Картинки песен — как добавлять

Справка для оператора/разработчика. Механику доставки см. также в `DEPLOY.md` §1.10.

## TL;DR

```bash
# 1. положи картинку с именем = номер песни:
#    deck/assets/songs/1041.png
# 2. одна команда:
dcimg 1041
```
Готово: оператор выбирает **№1041** в форме → на слайде картинка.

## Что делает `dcimg N`

`build/add_image.sh N` (алиас `dcimg` в `~/.zshrc`):
1. `png → webp` (q85, ~100–150 КБ вместо 1.5–2 МБ; гибрид ищет webp первым);
2. rsync webp в **ОБЕ** папки на VPS: `deck/assets/songs/` и `dist/assets/songs/`;
3. проверка: `GET /assets/songs/N.webp` → 200 **и** номер есть в `/api/song-images`;
4. печатает `OK: №N готов`.

В текущем окне терминала сначала подхвати алиас: `source ~/.zshrc`.
Без алиаса напрямую: `bash build/add_image.sh 1041`.

## После доставки — закоммить webp

`dcimg` только доставляет, git не трогает (можно накидать несколько, потом разом):
```bash
git add deck/assets/songs/1041.webp && git commit -m "feat(deck): song image №1041" && git push
```
png коммитить не нужно — он в `.gitignore` (тяжёлый исходник, только webp в репо).
Коммит нужен, чтобы полный редеплой (rsync `deck/` + пересборка `dist/`) сам нёс картинку.

## Как это устроено (почему две папки)

Слайд песни — **гибрид**, приоритет: **картинка → текст каталога → заглушка «№N нет»**.
Связь только по номеру: имя файла `N.webp` = номер, который выбирают в пикере.

- `deck/assets/songs/` — по ней сканирует FastAPI `/api/song-images`
  (`SONGS_ASSET_DIR = ROOT/deck/...`), чтобы дек **узнал**, у каких номеров есть картинка.
- `dist/assets/songs/` — из неё Caddy **отдаёт байты** (static-root).

Доставка только в `dist/` НЕ сработает: эндпоинт вернёт `{}` и дек не покажет картинки.
Только в `deck/` — Caddy отдаст SPA-fallback вместо файла. `dcimg` кладёт в обе.

Рестарт сервиса не нужен — эндпоинт сканирует папку на каждый запрос.
Логику гибрида не трогаем — она в `deck/slides/song.js` + `deck/merge.js`, работает.

## Форматы и приоритет

- Ищутся `assets/songs/N.{webp,png,jpg}`, первый по приоритету `webp > png > jpg`.
- Нет `cwebp` на Маке → `dcimg` шлёт png как есть (не блокирует).
- Размер исходника: ориентир 1440×810 (как извлечено из PDF), ресайз не обязателен.

## Проверка вручную (если надо)

```bash
curl -sI https://dc.vnedrum.ru/assets/songs/1041.webp | head -1        # HTTP/2 200
curl -s https://dc.vnedrum.ru/api/song-images | python3 -c "import sys,json;print('1041' in json.load(sys.stdin))"
```

## Текстовая песня (без картинки) — другой путь

Если у песни нет картинки, а нужны строфы из каталога:
`build/add_song.py` (ввод «двух полей» → `data/songs_seed.json`) → на VPS `seed_songs.py`
заливает в таблицу `song`. Это НЕ про картинки и НЕ через форму.
