# UI-SPEC — dc-deck

Финальная спецификация вида. Задание для Claude Code: «подними каркас до UI-SPEC».
Каркас (M0) уже держит контракт данных; эта спека доводит `operator.html` и `deck/slides/*` до целевого вида.

Принцип неизменен: **человек правит данные, не вёрстку.** Смена вида слайда = правка шаблона/токенов, не форма оператора.

---

## ЧАСТЬ A — ДЕК (проектор, 16:9, тёмная тема)

Порядок слайдов:
```
info(opening) → song×N → video → dada → info(continuation) → music
```

### Токены (theme.json — смена палитры в одном месте)
- `accent` — заголовки, время в программе (пример: тёплый оранжевый).
- `slide_bg` — фон info/служебных слайдов (тёмный, пример #14161f).
- `text_main` — основной текст (#F2EEE6).
- `text_muted` — вторичный (#9DA3B4).
- `song_translit_color` — транслит песни (#F2EEE6).
- `song_translation_color` — перевод песни, курсив (#C9C4D4).
- `font_heading`, `font_body`.

### Слайд `info` — ДВЕ КОЛОНКИ, два режима

Один шаблон, параметр `mode ∈ {opening, continuation}`. Правая колонка одинакова в обоих режимах; по режиму меняется только левая.

**Левая колонка (зависит от mode):**

| Слот | opening | continuation |
|---|---|---|
| приветствие | «Намаскар!» + строка по правилу 12:00 (см. ниже) | «Намаскар!» + «Благодарим за коллективную практику» |
| заголовок программы | «Программа на сегодня:» | «Далее в программе:» |
| программа | все пункты | только пункты ПОСЛЕ маркера границы |
| футер | «Пожалуйста, выключите таймеры и звуковые сигналы» | «Благодарим, что соблюдали тишину» |

Пункт программы: `[время accent] [текст]`, курсивная `note` под пунктом если есть.

**Правая колонка (одинакова, сверху вниз, жёстко прижата):**
1. «Новости юнита» — заголовок.
2. Буллеты новостей (переменная высота, см. конвейер новостей). Ограничить высоту — не выдавливать нижние блоки.
3. Прогресс-бар: «собрали X / Y ₽» + процент. `plan=0` → скрыт.
4. QR + «человечек» (статичный ассет, «Не забывайте поддерживать джа!»). Прижат к низу.

**Риск вёрстки (единственный на info):** новости сверху с max-height, бар и QR прижаты к низу колонки (`margin-top:auto`). Много событий не должны сдвинуть QR за край слайда.

**Правило приветствия (opening), слайд-1:**
```
start = program[0].time (после оверрайдов), "HH:MM" МСК
hour < 12  → строка с «Маунавратой»   (GREETING_MORNING)
hour >= 12 → без неё                    (GREETING_DAY)
программа пуста / не распознано → GREETING_MORNING
```
Обе строки — константы шаблона. Сравнение по МСК из строки, НЕ по времени сервера. `MORNING_CUTOFF_HOUR = 12`.

**Правило границы «Далее» (continuation):**
- Один пункт помечен `is_practice_end` (маркер «конец коллективной части»).
- continuation показывает пункты ПОСЛЕ помеченного.
- Маркер по названию НЕ детектится (практика меняет имя: Дхармачакра / Садхана Шивир / …). Дефолт — на пункт, похожий на практику (Дхармачакра как частый случай), человек двигает в редакторе.
- Ни один не помечен → показать все пункты (безопасный фолбэк, не рисковать пустым «Далее»).

### Слайд `song` (×N) — тёмный фон темы, две колонки
- Заголовок по центру: «Прабхат Самгит {number}» акцентом; `subtitle` под ним если есть.
- Левая колонка: `stanzas[].translit` (заглавные, `song_translit_color`).
- Правая колонка: `stanzas[].translation` (курсив, `song_translation_color`).
- Строфа к строфе (выравнивание по строфам, не по строкам).
- Фон = `background_ref` песни; файла нет → дефолт `song_background` из theme.
- `footnote` если есть — мелким внизу. `lang="en"` (№68) — «транслит» уже английский, рендерить как есть.
- Номер не найден в каталоге → слайд-заглушка «№X не найден».

### Слайд `video`
- `video_url` есть → YouTube-iframe на весь слайд.
- Пусто ИЛИ iframe не поднялся (флаки-VPN) → заглушка «видео сегодня нет».

### Слайд `dada`
- Слева карточка: «комментарий» + `dada_comment` (пусто → дефолт-текст).
- Справа круглое фото Дады (ассет).

### Слайд `music` (финал)
- `final_music_url` есть → YouTube-iframe. Пусто → слайд скрыт (не показывать пустой).

## ЧАСТЬ B — ФОРМА ОПЕРАТОРА (мобайл, тёплая студийная эстетика, один accent)

Открывается по URL под basic-auth (`GET /api/operator`). Без VPN (VPS в РФ). Авто-сохранение — без кнопки «сохранить».

### Шапка
- «Сборка на {дата}» + контекст недели.
- Индикатор «сохранено автоматически» (облако+галка). Иконка-замок.

### Секция «Собирается само» (свёрнуто, зелёная галка)
Строки: «Программа» (N пунктов · из Telegram) и «Новости юнита» (N событий · из Airtable). Тап → разворот в редактор (Часть C).

### Секция «Твоя часть» (акцентная рамка)
- **Песни:** input номеров через запятую. Каждый номер резолвится в карточку [№][транслит][перевод] с × для удаления. Номер не найден → карточка-заглушка.
- **Видео:** одно поле URL. Подсказка пустого состояния: «пусто — покажем слайд „видео нет"».
- **Сбор средств:** два поля (собрали / план) + живой прогресс-бар под ними.

### Действия
- «Собрать и открыть дек» (primary), «Превью», «PDF».

### Состояния
пусто / заполнено / резолв-успех / резолв-заглушка / изменено / сохранено. Каждое — визуально отличимо без обучения.

## ЧАСТЬ C — РЕДАКТОР (разворот секций «собирается само»)

Режим «влезть и поправить». Правки пишутся в `selection.overrides`, НЕ в manifest (переживают пересборку).

### Программа (разворот)
- Список строк `[грип][время][текст][×]`. Добавить (пунктирная кнопка), удалить, перетащить.
- **Маркер границы** `is_practice_end` — радио на одном пункте, «конец коллективной части». Двигается человеком.
- **Подсветка неуверенности LLM:** строка на жёлтом фоне + «LLM не был уверен во времени — проверь».
- Бейдж происхождения: «из Telegram» → при правке «изменено вручную» (жёлтый).
- Кнопки: «Сбросить к авто» (очищает overrides.program → null), «Готово».

### Новости (разворот)
- Список буллетов, правка/удаление/добавление/перетаскивание.
- **Ручные новости** добавляются здесь же (диапазоны многодневных «Поход 10–16 августа», разовые «Ребёнок родился!»). Живут в `selection.overrides.news_manual`.
- Бейдж «из Airtable» → «изменено вручную». Сброс к авто.

**НЕ редактируется в форме:** шрифты, цвета, фоны, положение блоков. Дизайн — константа кода.

## ЧАСТЬ D — КОНВЕЙЕР НОВОСТÉЙ (build/fetch_news.py, Мак, детерминированный)

Airtable из РФ с VPS блокируется → билд на Маке. LLM здесь НЕ участвует.

Идентификаторы:
- base `appgi18TrXayt3VSG`, table `tbl5P4t8CTqEE8sLv`
- поля (field ID, `returnFieldsByFieldId=true`): Name (from Название) `fldVK7klidt4z84OB`, Дата `fldWA3TKUvyWJsNqv`, Тип `fldARjqaf6N1hnwCv`, status (по имени в формуле).

Пайплайн:
```
GET Календарь мероприятий
  → filterByFormula: AND({status}='published', Дата в окне [сегодня … конец календарного месяца])
  → отбросить записи без Name (from Название)        # призраки-записи
  → словарь показа (build/news_show.json):
        Name в "announce" → взять
        Name в "routine"  → пропустить
        новое имя         → взять + пометить «новый тип, реши» (безопасный дефолт)
  → Name (from Название) = готовый человекочитаемый текст (СВОЙ словарь расшифровки НЕ нужен — он в Airtable)
  → свёртка одинаковых Name: одна строка, даты рядом  # «Коллективная медитация — 1, 8, 15 авг»
  → ∪ ручные новости из формы (selection.overrides.news_manual)  # диапазоны многодневных + разовые
  = news[] для правой колонки info-слайда
```

Заметки к схеме (проверено на живом API):
- `Тип` = направление (УМ / АМ / Эксклюзив), НЕ признак «показывать». Отсекать рутину по нему нельзя.
- Многодневные события в Airtable — ОДНОЙ датой, поля начало-конец нет. Диапазон «10–16» из Airtable недостижим → только ручной слой.
- Окно = до конца календарного месяца. 1-го числа список обнуляется на новый месяц.

## Приоритет реализации (по PLAN.md, не всё сразу)
1. Дек: info(2 колонки, 2 режима) + song + video + dada + music — по этой спеке (M0-доводка).
2. Форма/редактор — по Части B/C.
3. Новости — сначала голый `status+дата+Name → буллеты`, затем словарь показа + свёртка + ручной слой (M3). Не увязать в свёртке до проверки живого потока.
