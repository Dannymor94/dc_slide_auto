# PLAN — dc-deck

Вехи серийные. Одна активная за раз. На каждом стоп-гейте — остановка и подтверждение человеком
до перехода к следующей. Без автономного продолжения.

Активная веха помечена `← ТЕКУЩАЯ`.

---

## M0 — Скелет и контракт ← ТЕКУЩАЯ

**Цель:** дек рендерится из статичных данных, контракт зафиксирован, форма пишет selection.

**Делаем:**
- Структура репозитория, `DECK-CONTRACT.md`, `theme.json`, `manifest.schema.json`.
- Дек reveal.js: `boot.js` (fetch theme+manifest+selection+catalog → merge → render), все шаблоны слайдов со слотами и заглушками.
- Слайд 1: правило утро/вечер (12:00 МСК) из времени старта программы.
- Сервер FastAPI: `GET /api/selection`, `GET /api/catalog`, `POST /api/selection` (basic-auth), `/operator` (форма, basic-auth).
- Postgres: таблица `song`, `seed_songs.py`, sample-сид на 2 песни (№1, №63).
- Форма: секция «собирается само» (программа/новости, свёрнуто, разворот в правку → overrides) + «твоя часть» (песни/видео/деньги).
- Caddyfile + systemd-юнит.

**Стоп-гейт (done):**
- Дек открывается на `dc.vnedrum.ru`, рендерит все слайды из `sample/manifest.sample.json` + пустого selection.
- В форме выбрал песню №1 → карточка резолвится из каталога → слайд песни появился.
- Правка строки программы в форме → сохранилась в `overrides` → пережила повторную заливку manifest.
- Пустое видео → слайд «видео нет». Сервер недоступен → дек рендерит по manifest + баннер «нет связи».

## M1 — Каталог песен (реальный)

**Цель:** полный сид всех Прабхат Самгит из PDF, резолв любого номера.

**Делаем:** `songs_seed.json` (транслит + перевод + фон по каждой песне), загрузка в Postgres, резолв в форме по любому номеру каталога.

**Стоп-гейт:** ввёл в форме несколько реальных номеров → все карточки резолвятся, слайды песен корректны (транслит слева, перевод справа, фон).

---

## M2 — Программа из Telegram (точка LLM)

**Цель:** авто-извлечение расписания, человек проверяет.

**Делаем:**
- MVP: `extract_program.py` — вставленный текст поста-программы → JSON `{date, items:[{time,title,note?}]}` через Groq. Подсветка неуверенных строк.
- Позже (не в этой вехе): Telethon-подтяжка канала Rostov Unit, фильтр по отправителю.

**Стоп-гейт:** реальный пост из чата → корректное расписание в manifest → в форме видно, правится, оверрайд работает.

---

## M3 — Новости и деньги из источников

**Цель:** новости из Airtable, прогресс без ручного ввода (если возможно).

**Делаем:** `fetch_news.py` (Airtable API, окно дат). Деньги: определить источник числа «собрали» выше по потоку; если нет — ручное поле остаётся.

**Стоп-гейт:** manifest собирается с реальными новостями; прогресс-бар заполнен корректно.

---

## M4 — Оператор-финиш

**Цель:** сборка одной кнопкой, PDF, полировка.

**Делаем:** кнопка «Собрать и открыть», превью, `?print-pdf` экспорт. Aliasы Мак-билда (один запуск в неделю). Fallback iframe видео → заглушка.

**Стоп-гейт:** полный воскресный цикл проходит без ручной вёрстки: Мак-билд → пуш → человек в форме выбирает песни/видео → открывает дек.

---

## Бэклог (не тянуть до валидации M0–M2)

- Telethon авто-подтяжка канала (замена вставки текста в M2).
- Airtable/Sheets через входящий вебхук (если уйдём от Мак-билда).
- OCR прогресс-бара из картинки (только если нет источника числа выше по потоку).
- Смена темы/макета — правки `theme.json` и шаблонов слайдов, вне операторской формы.
